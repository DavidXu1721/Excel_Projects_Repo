# Excel Data Analysis | Data Technician Bootcamp

## Project Overview

This project showcases Excel data analysis skills developed during Week 1 of the **Leep Talent Data Technician Bootcamp (September 2026)**.

Using retail and sales datasets, I applied Excel formulas, data filtering, sorting, PivotTables and visualisations to analyse sales performance, identify trends and present business insights.

## Skills & Tools

**Tool:** Microsoft Excel

- **Formulas & Functions:** `SUM`, `SUMIF`, `AVERAGE`, `AVERAGEIF`, `DATE`, `MONTH`, `YEAR`, `UNIQUE`, `VLOOKUP`
- **Data Manipulation:** Filtering, sorting and organising datasets
- **PivotTables:** Summarising sales, revenue and profit across different categories
- **Conditional Logic:** Using `SWITCH` to classify sales volumes into High, Medium and Low categories
- **Data Visualisation:** Creating line, bar and pie charts to communicate trends and comparisons

## Project Tasks

### 1. Retail Sales Analysis
- Sorted and filtered customer transaction data.
- Calculated total and average sales commissions using Excel formulas.
- Practised using functions to summarise and analyse numerical data.

### 2. Bike Sales Analysis
- Created PivotTables to analyse sales and profitability by country, age group and gender.
- Compared regional sales performance and customer demographics.
- Identified the United States as the most profitable country in the dataset.
- Observed higher purchasing activity and profitability among female customers.

<img src='/images/Day3_Task1.png' />

### 3. Sales Performance Categorisation
- Created a PivotTable summarising laptop, smartphone and printer sales across English counties.
- Used the `SWITCH` function to categorise sales volumes:
  - **High:** Greater than 600
  - **Medium:** 300–600
  - **Low:** Below 300

### 4. Data Visualisation
- Created line charts to compare revenue and profit over time.
- Used bar charts to compare product revenue across countries.
- Created pie charts to visualise revenue distribution across age groups.

## Key Takeaways

This project strengthened my ability to organise, analyse and visualise data using Excel. It provided practical experience in transforming raw sales records into structured summaries and identifying patterns through PivotTables and charts.

The project also reinforced the importance of presenting data clearly to support business decision-making.
